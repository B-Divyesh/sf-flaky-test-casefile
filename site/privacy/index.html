Privacy

Privacy for local casefiles

Effective September 5, 2026

The package

Flaky Test Casefile runs on your machine or CI runner. It does not upload reports or send usage telemetry. Generated reports are static local files.

Artifact safety

Credential headers and sensitive query values are redacted from probe data. Traces and videos are excluded by default. Configured screenshot masks change the copied PNG pixels.

This website and demo

The website uses no analytics, advertising, cookies, third-party fonts, third-party scripts, or runtime CDN. A selected JSON file is processed in browser memory and is not uploaded or saved. The demo uses a separate demo: storage namespace. Its service worker caches public files after the first visit for offline use.

Contact

Questions can be filed in the project’s public GitHub issue tracker. Do not include private test artifacts or credentials in an issue.
