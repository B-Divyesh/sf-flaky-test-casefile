Privacy

Effective August 27, 2026

The package

Flaky Test Casefile runs on your machine or CI runner. It does not transmit reports, tests, screenshots, identifiers, or usage telemetry to us. Generated reports are static local files.

Artifact safety

Test artifacts can contain personal data or credentials. Credential headers are redacted from probe data, traces and videos are excluded by default, and optional screenshot masks alter the copied PNG pixels. You control storage and sharing. Review any report before distributing it.

This website

The demo processes a selected JSON file only in browser memory. It does not upload or persist that file. The site uses no analytics, advertising, cookies, third-party fonts, or third-party scripts. Its service worker caches public site files on your device for offline access; clearing site data removes them.

Contact

Questions can be filed in the project’s public GitHub issue tracker. Do not include private test artifacts or credentials in an issue.
