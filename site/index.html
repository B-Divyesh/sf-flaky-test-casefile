Install

Add the reporter to Playwright

Generate a static casefile with your normal test run.

playwright.config.ts
reporter: [
  ['line'],
  ['flaky-test-casefile', {
    outputDir: 'casefile-report'
  }]
]

×

What stays local

Reports are local files. Credential headers and sensitive query values are redacted. Traces and videos stay out by default.
