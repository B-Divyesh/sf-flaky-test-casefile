Two-minute setup

A reporter, not another platform.

Add one reporter entry. The result is a portable report your CI can retain like any other artifact.

playwright.config.ts
reporter: [
  ['line'],
  ['flaky-test-casefile', {
    outputDir: 'casefile-report'
  }]
]
